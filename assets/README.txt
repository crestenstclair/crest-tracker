Window Light — bundled Crest Tracker example

This original demonstration arrangement and its five Braids sound definitions
were authored for Crest Tracker. It contains no imported recordings, samples,
SoundFonts or third-party musical material. The sound engine and the resources
shipped with Crest Synth retain their existing licenses and notices, which are
included separately in the macOS application's Resources directory.

window-light.crest-song is a complete portable Song with pinned sound revisions,
local routing/mix, off-grid notes and owned member/master expression. Open it
through the Song file chooser or choose Main menu > Load Example. Loading uses
the normal unsaved-work guard. New Song remains empty.

The canonical authoring fixture lives in
crates/crest-tracker-app/src/synth/fixture_authoring.rs. Its comparison test detects
drift between the bundled file and the native Synth types that authored it.
